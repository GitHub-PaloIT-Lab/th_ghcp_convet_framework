# Convert Framework Workshop - Quick Reference

## 🚀 Get Started in 30 Seconds

```bash
git clone <repo-url> && cd convert-framework
make help                    # See all commands
make run-url                 # Try Go URL Shortener
make run-blog                # Try Go Blog API
make run-weather             # Try Python Weather CLI
make run-scraper             # Try Python Web Scraper
```

## 💡 User Journey

### First-Time User:
1. Clone repo
2. See Quick Start in main README
3. Run `make help` or `make run-url`
4. App starts immediately ✨

### Learning User:
1. Pick an app from main README
2. Read app's README for details
3. Check `docs/COPILOT_GUIDE.md` for AI tips
4. Start converting with Copilot

### Advanced User:
1. Jump straight to `docs/IMPLEMENTATION_PLAN.md`
2. Use Makefile commands
3. Reference app READMEs as needed

## 🔧 Makefile Commands

```bash
make help          # Show all commands
make run-url       # Run Go URL Shortener
make run-blog      # Run Go Blog API
make run-weather   # Run Python Weather CLI
make run-scraper   # Run Python Web Scraper
make setup-go      # Install Go dependencies
make setup-python  # Setup Python environments
make clean         # Clean build artifacts
```
